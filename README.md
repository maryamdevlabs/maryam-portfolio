# Maryam — Frontend Developer Portfolio

A modern, responsive personal portfolio built with React and Vite to showcase my web development projects, skills, and services.

## 🌐 Live Website

**[Visit my portfolio](https://maryam-portfolio-rust.vercel.app/)**

## ✨ About the Project

This portfolio was designed and developed to present my work as a frontend developer and showcase the types of websites and digital experiences I build.

It includes selected projects, technical skills, services, and contact information for potential clients and collaborators.

## 🚀 Features

* Responsive design across desktop, tablet, and mobile
* Modern dark-themed interface
* React component architecture
* Smooth navigation between sections
* Interactive hover effects and animations
* Accessible keyboard focus states
* Reduced-motion support
* SEO-friendly page metadata
* Direct links to live projects and GitHub repositories
* Contact section with professional email
* Vercel deployment
